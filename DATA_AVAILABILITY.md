# Data and code availability

The current public release contains study-specific downstream analysis and plotting scripts, method documentation and references. It does not contain raw imaging, regional time series, individual structural or functional connectomes, participant-level clinical or covariate data, participant-level derived matrices, parcellation files, or aggregate result tables.

The scripts require authorized private inputs, including precomputed NSP/gradient/graph inputs and spatial-spin operators. NSP, BrainSpace, CATO, and FreeSurfer upstream implementations are cited and linked in `REFERENCES.md`; their source code is not redistributed here.

Participant-level data are not included because of participant confidentiality and applicable ethical and institutional requirements. A controlled-access workflow has not been established by this code-only release. Do not advertise controlled data access as currently available until the responsible institution, contact, eligibility criteria, transfer mechanism, and approval process have been confirmed.
